# SGCourt - Singapore Pickleball DUPR Community League

**SGCourt** is a modern, responsive web application for Singapore's local pickleball groups, clubs, and competitive ladders. Inspired by DUPR (Dynamic Universal Pickleball Rating) and tournament bracket systems.

Built with **Supabase (Cloud Backend / PostgreSQL)** and **Static Web (HTML5 + Vanilla JS + Tailwind CSS)**. Ready to deploy globally on Cloudflare Pages, GitHub Pages, or Vercel.

---

## ⚡ Key Pickleball Features

1. **Pickleball DUPR Leaderboard**:
   - Live DUPR rating tags (e.g. `DUPR 4.85`, `DUPR 4.25`) & skill tiers (Advanced 4.5+, Intermediate, Club Player).
   - Paddle gear showcase (Joola Ben Johns Perseus, Selkirk Vanguard Power Air, CRBN 1X, etc.).
   - Current Elo rating, peak rating, total matches, win percentages, and real-time search.
2. **Tournament & Pool Play System**:
   - **Pool Play Cross-Matrix**: Round-robin grid showing game scores (e.g., `11-7, 11-8`), game differentials (+/-), and win-loss records.
   - **Championship Knockout Tree**: Visual progression through Semi-Finals, Bronze Match Playoff, and Grand Championship Final (Best of 3, 11-pt win by 2).
   - **Final Standings & DUPR Delta**: Pre-event rating, rating exchange ($\pm \Delta$), and post-event rating.
3. **Head-to-Head (H2H) Court Clash**:
   - Select any two pickleball players to inspect their lifetime record, game scores, and win rate bar.
4. **Court-side Chat (Message Board)**:
   - Anonymous or signed chat for local players to organize open play, discuss paddles, review tournament games, and give high-fives (likes).
5. **English & 中文 Language Toggle**:
   - Seamless one-click switch on the top right.
